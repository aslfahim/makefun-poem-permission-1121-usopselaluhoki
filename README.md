A short poem about agency — the power to ask and to be given — told at the shoreline: a grandad teaches his grandson to ask the sea properly, knuckle not fist, and to accept what the net brings back, heavy or light.

## Run it

```sh
python3 main.py
```

The program writes the poem to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
